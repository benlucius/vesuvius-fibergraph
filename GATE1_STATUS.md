# FiberGraph Gate 1 status

Date: 2026-09-13

## Gate definition

Gate 1 asks a narrower question than end-to-end tracing:

> Given fragmented candidate traces following real human-annotated papyrus-fiber geometry, can the global assembler reconnect them without crossing fiber identity?

The source is the public ScrollPrize Scroll 5 WebKnossos skeleton file `fibers_s5_06500z_02000y_04000x_500_v03.nml` (Git blob `4a42c6b89f0b7e50f5331ce809efd6fb44a846b4`, source page reports 4.24 MB). A curated decimated subset contains 14 fiber instances. Every retained XYZ coordinate is a real source node; omitted source nodes are simply decimation.

Nine fibers were used during development. Only after fixing the precision-first linker configuration, five later source fibers were transcribed as the untouched Gate-1 set: `186, 187, 189, 196, 197`.

## Linker change made during Gate 1

The phase-0 ambiguity rule was strengthened. A candidate link now has to be the **mutual local winner at both endpoints**, in addition to clearing the ambiguity margin. This prevents a global matching objective from choosing a locally second-best cross-fiber edge merely because it increases total graph weight.

Frozen configuration:

- maximum endpoint gap: 32 voxels
- maximum bridge/tangent angle: 30 degrees
- ambiguity margin: 0.15 score units
- mutual-best requirement: enabled
- minimum score: 0

The development set deliberately contains close pairs (`165/166`, `170/171`). Across 100 randomized fragment/jitter seeds at each condition, the frozen configuration produced zero wrong links. At the hardest development condition it recovered 52.83% of true joins. A more permissive 40-degree angle gate recovered 77.33%, but produced a cross-fiber error in 1/100 seeds. We therefore kept the lower-recall 30-degree gate.

## Interpretation / limitation

This clears the project's first **assembly-only** gate, not an end-to-end Vesuvius tracing gate. The candidate traces are generated by fragmenting/resampling the GT skeleton geometry, so the experiment cannot measure local tracer drift, model hallucination, CT ambiguity, or seed discovery. It also uses a small curated subset from one annotation cube.

## Gate 2

Generate candidate tracklets without access to GT geometry:

1. sample the existing Vesuvius multi-branch direction/presence predictions;
2. propose seeds automatically;
3. obtain local traces using the native VC3D `native_fiber_trace3d` tracer rather than a duplicate tracer;
4. run FiberGraph only for deduplication/global connectivity;
5. score against withheld NML skeletons with the exact same link/identity metrics;
6. keep the precision-first gate: a large recall gain does not compensate for cross-fiber identity errors.
